# Constitución de AI BROKER

1. Aislamiento estricto por agencia mediante `tenant_id`.
2. BROKER es el único interlocutor y escritor de memoria canónica.
3. Privacidad desde el diseño; documentos originales y PII fuera de Git.
4. Evidencia, fuentes vigentes y revisión humana en asuntos relevantes.
5. Especificación antes del código y validación requisito por requisito.
6. Toda acción externa requiere autorización inmediata.
7. El núcleo es internacionalizable; las reglas españolas viven en el módulo Spain.
